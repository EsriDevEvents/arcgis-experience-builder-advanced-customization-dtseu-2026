# ArcGIS Experience Builder: Advanced Customization

Join us to explore advanced solutions with the developer edition of ArcGIS Experience Builder. In this technical session, speakers cover deeper topics for building custom widgets, including widget communication, data sources, automated deployments, custom widget source code collaboration, connecting to the Map component from ArcGIS Maps SDK for JavaScript, and more.

## How it works
1. Clone the repo into the client folder of your experience builder dev edition
2. Copy the content of the apps folder to server/public/apps
3. Run npm start in client and server folder of your experience builder dev edition
4. Open the sample apps with
   https://localhost:3001/experience/basic-widget?draft=true or
   https://localhost:3001/experience/maps-sdk?draft=true or
   https://localhost:3001/experience/halloween-app
